# Выбор среды для работы с файлами через Windows MCP

**Область применения:** Windows MCP и работа с файлами на удалённом Windows-компе. Это не регламент выбора среды сборки или тестирования Linux-проектов.

## Правило по умолчанию

При запросе на **анализ содержимого** офисного файла из списка ниже:
1. Через Windows MCP установи путь, расширение и размер — без запуска анализа содержимого.
2. Если файл **не больше 20 МиБ** и передача поддерживается, получи копию в аналитическую среду ChatGPT. Анализируй там.
3. Windows MCP используй для проверки поведения установленного приложения, состояния ОС и результата на целевом ПК.
4. Если файл больше 20 МиБ или передача не поддерживается, не выгружай его автоматически: предложи точечную удалённую проверку либо запроси решение пользователя.

**Форматы для локального анализа:**
- Документы: `.doc`, `.docx`, `.docm`, `.rtf`, `.odt`.
- Таблицы: `.xls`, `.xlsx`, `.xlsm`, `.ods`.
- Презентации: `.ppt`, `.pptx`, `.pptm`, `.odp`.
- PDF: `.pdf`.

Не выполняй встроенные макросы. Список относится только к **анализу содержимого**, а не к простому редактированию документа в установленном Word/Excel.

## Что остаётся на удалённом ПК

- `.txt`, `.log`, `.ini`, а также конфигурации, скрипты и диагностические выгрузки: начинай с точечного чтения через Windows MCP; не копируй автоматически по одному расширению. Это не запрет на последующую передачу по задаче.
- Поиск файла, проверка размера/атрибутов, диагностика Windows, GUI, печать, установленное ПО — Windows MCP.
- Простое изменение в открытом Word/Excel по поручению пользователя — непосредственно в приложении; локальная копия необязательна.

**Передача:** просьба проанализировать определённый файл — разрешение передать его копию в ChatGPT; других файлов она не касается. Проверка конфиденциальности автоматически не выполняется. Нет инструмента передачи — не изображай, что файл получен.
