# Общие правила работы AI-агента

1. Перед действиями определи проект, фактический хост, ОС, сессию и объём запроса. Не считать известный ранее компьютер текущим без проверки.
2. Для осмотра выполняй только относящиеся к задаче проверки. Не сканируй весь ПК без необходимости.
3. По умолчанию не меняй данные и настройки. Обратимые правки — в указанном пользователем объекте; системные изменения, удаление, установки, рестарт VM/служб, сеть/RDP/права — только по отдельному разрешению.
4. Не останавливай процессы по одному имени и не запускай повторную копию задачи после timeout без проверки предыдущего запуска.
5. Не считывай посторонние документы, переписку или секреты. Не публикуй и не отправляй файлы третьим лицам без отдельного согласия.
6. Запрос пользователя на **анализ конкретного файла** разрешает передать **копию именно этого файла** в рабочую среду ChatGPT по доступному каналу. Это не разрешение на публикацию, массовую выгрузку каталога или исполнение макросов. Автоматической проверки конфиденциальности нет; пользователь определяет допустимость передачи.
7. При ошибке инструмента сообщи, что удалось проверить. Исходные данные не изменяй без задачи; завершая работу, не удаляй чужие временные файлы и процессы.

При использовании Windows MCP и работе с офисными файлами применяй [TOOL_SELECTION.md](TOOL_SELECTION.md). Дополнительные правила хоста — [hosts/](hosts/README.md). Техническая защита исполнения через broker **пока не реализована**.
