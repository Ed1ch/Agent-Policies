# Профили хостов

Читать профиль только после определения целевого ПК. Профиль дополняет [GENERAL.md](../GENERAL.md), но не выдаёт новых прав и не доказывает идентичность хоста.

- [ELDAR.md](ELDAR.md) — черновик; не активная серверная политика.
- Не хранить в профилях секреты, личные пути, токены и несущественные сетевые адреса.
- Если профиль отсутствует или не подтверждён, не угадывать настройки и не переносить ограничения другого ПК.
