# ELDAR — справочный профиль

**Область:** только после подтверждения идентичности компьютера ELDAR; профиль не применять к другим хостам.

**Статус:** черновик, не активная server policy.

- Рабочий ПК: не считать его текущим хостом до проверки.
- VPN, туннели, RDP, VM и пользовательские процессы считать рабочими; не перезапускать без разрешения.
- Для GUI проверять доступность нужной пользовательской сессии.
- Рестарт VM/служб, операции с Codex, сетью и установкой ПО требуют отдельного согласия.
- Не завершать процессы по одному имени. Доверенная host identity пока не реализована.
